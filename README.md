# Linking Path-Dependent and Stochastic Volatility Models

Code and data for Chapter 2 of the DPhil thesis *Path-Dependence in Volatility and Risk*
(C. Svosve, University of Oxford), based on the preprint

> S. N. Cohen and C. Svosve, *Linking Path-Dependent and Stochastic Volatility Models*,
> [arXiv:2510.02024](https://arxiv.org/abs/2510.02024).

## Idea

A stochastic volatility (SV) model, viewed in the filtration generated by its returns, is a
path-dependent volatility (PDV) model, since the conditional expectation of the latent
variance given past returns is a function of the return path. We make this explicit with an
**assumed density filter (ADF)**. The filter carries an Inverse-Gamma belief about the
variance, updates it with each return and projects back by moment matching. The result is a
weighted average of past returns and squared returns, whose weights adapt to the filter's
uncertainty through $Q = M^2/V$, the squared ratio of the filtered mean to its standard
deviation, and are fixed by the SV parameters rather than fitted. Holding $Q$ constant
recovers the PDV form of Guyon and Lekeufack.

## What the notebook does

1. **Core functions.** These are the Heston simulator (full-truncation Euler, correlated
   increments), the ADF (Algorithm `alg:ADF1`: correction, prediction, projection), the
   constant-Q filter, the PDV model and its inversion to Heston parameters, and the
   least-squares calibration of the filter.
2. **Simulation study.** This covers the filter at the true parameters, the stability of
   Q, the constant-Q approximation, a comparison with a fitted PDV model over 25
   independent paths, PDV-based and ADF-based parameter estimation, and standard errors
   from the true sampling distribution and the parametric bootstrap.
3. **Real data.**
   - Next-day realised volatility (Oxford–Man 5-minute realised variance).
   - Same-day VIX, with target $(\mathrm{VIX}/100)^2/365$.
   - Both are calibrated on January 2001 – December 2008 and evaluated out of sample on
     January 2009 – June 2018, the end of the Oxford–Man data, with bootstrap standard errors.
4. **Summary.** This prints every number used in the chapter, including the
   leverage-fallback counts (Remark `rem:leveragefallback`), and writes
   `results_chapter2.json`.

## Running it

```bash
git clone https://github.com/CephasSvosve/Linking-PDV-with-SV-models.git
cd Linking-PDV-with-SV-models
pip install numpy scipy pandas matplotlib jupyter
jupyter notebook "Linking-PDV-with-SV-Models-updated_08_10_2026.ipynb"
```

Run all cells. The notebook reads `Vol_Index.csv` from the same folder and writes figures
to `figures/`. The bootstrap (`N_BOOT = 100`) dominates the run time. Lower `N_BOOT` in the
settings cell for a quick check, which changes only the standard errors.

The reference run used Python 3.12.3, NumPy 1.26.4, SciPy 1.11.4, pandas 2.1.4 and
Matplotlib 3.6.3, with seed 2026. Results agree to machine precision with newer versions.

## Key results

| | In sample | Out of sample |
|---|---|---|
| Simulation, filter at true parameters (R², variance) | 0.699 | 0.700 |
| Realised volatility, next day (R², volatility) | 0.723 | 0.608 |
| VIX, same day (R², volatility) | 0.912 | 0.856 |

The variable-Q ADF matches or exceeds a fitted PDV model on 23 of 25 simulated paths, with
nothing fitted to the volatility. The leverage fallback was not used at any step of any
reported run.

## Data

`Vol_Index.csv` holds daily `Date`, `VIX` (Cboe VIX close), `SPX` (S&P 500 close), and
`SPX_OX` and `RVOL_5min` (S&P 500 close and 5-minute realised variance from the Oxford–Man
Institute Realized Library). Log returns are computed from `SPX_OX`.
